Deutsch (Kontrolle für den Autor)

Hallo — das ist die „Erklärbär“‑Ansicht. Diese Seite erklärt kurz den Sachverhalt auf Deutsch, damit du prüfen kannst, ob Texte / Links korrekt sind.

  • Ursache: Die angeforderte Datei existiert nicht mehr oder hat einen anderen Namen.
  • Prüfe als Autor: Liegt die Datei im Repo‑Root? Ist die Groß-/Kleinschreibung korrekt (wichtig auf Linux/Webservern)?
  • Weitere Schritte: Falls die Datei fehlt, lade sie hoch oder passe Links an; für Hilfe öffne ein Issue (Link oben).

Empfehlung: Prüfe index.html, 404.html, net.html, 360.html und build.html auf korrekte Dateinamen und Links. Nutze README für Anleitungen.
