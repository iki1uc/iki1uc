MIR · Spiegel-/Betrachtungsebene

ID: MIR-01
ROLE: mirror-layer

DIMENSION:
  Ebene: 10
  Funktion: Spiegelung, Betrachtung, Analyse
  Bindung: Beobachtet alle ULRM-Module und NC-Formen

DATA:
  input: LAGE
  effect: "Spiegelung von x, y, z"
  modi: "MIR"

ENGINE:
  function MIR(LAGE){
      return {
          x: -LAGE.x,
          y: -LAGE.y,
          z: -LAGE.z,
          ghost: LAGE.ghost ?? null,
          modi: "MIR",
          role: "mirror-layer"
      };
  }

RESULT:
  MIR erzeugt eine vollständige Spiegelung der LAGE.
  Die Betrachtungsebene zeigt die invertierten Koordinaten.
