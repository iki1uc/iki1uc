PI – Kreis / Verhältnis

ID: ULRM-PI
ROLE: ratio
MODE: RAW / RESPO / Argumenteria
STATUS: active

DATA:
  pi: 3.1415926535
  relation: "Umfang / Durchmesser"
  effect: "rotierende Lage"
  respo: "Führung durch Kreisverhältnis"
  modi: "Y (rotate)"
  cube: "circle-face"
  rawator: "spin"
  mir: "Rotation sichtbar"
  pimp: "Betrachtung: Kreis"

ENGINE:
  function ULRM_PI(LAGE){
      const angle = (LAGE.angle ?? 0) + 3.1415926535;
      return {
          x: Math.cos(angle),
          y: Math.sin(angle),
          z: LAGE.z,
          angle: angle,
          modi: "PI",
          role: "ratio"
      };
  }

RESULT:
  LAGE rotiert proportional zum Kreisverhältnis (PI).
