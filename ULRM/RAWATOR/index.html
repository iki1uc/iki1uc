RAWATOR – Rohmotor / Neutralebene

ID: RAWATOR-CORE
ROLE: motor
MODE: RAW / NEUTRAL / DRIVE
STATUS: active

DIMENSION:
  Ebene: 11
  Funktion: Rohantrieb, Neutralmotor, Basisenergie
  Bindung: Speist alle ULRM-Module
  Axiom: vererbbar / erwerbbar / nutzbar / sys-gerecht

CLOCK:
  type: "clockwise"
  tick: "neutral-spin"
  cycle: 360°
  effect: "richtige Laufrichtung für alle ULRM-Achsen"
  anchor: "gravitation / magnet / zoog / echo / hall / rum / umrum / rundherum / richtigrum"

DATA:
  power: "raw"
  neutral: true
  drive: "vector"
  effect: "Grundbewegung für alle Achsen"
  modi: "RAW"
  cube: "motor-core"
  mir: "Motor sichtbar"
  pimp: "Betrachtung: Rohenergie"

ENGINE:
  function RAWATOR(LAGE){
      const tick = (LAGE.tick ?? 0) + 1;        // clock tick
      const angle = (tick % 360) * (Math.PI/180); // clockwise rotation

      return {
          x: Math.cos(angle),   // neutral-clock vector
          y: Math.sin(angle),   // neutral-clock vector
          z: LAGE.z,            // tiefe bleibt stabil
          tick: tick,
          angle: angle,
          raw: true,
          drive: "neutral-vector",
          modi: "RAW",
          role: "motor"
      };
  }

RESULT:
  RAWATOR erzeugt eine neutrale, uhrgerechte Grundrotation (clockwise 360°),
  die als Rohmotor alle ULRM-Module antreibt.
