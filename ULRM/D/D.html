ULRM-D · Rechts

ID: ULRM-D
ROLE: right

DATA:
  axis: y
  step: +1
  effect: "LAGE.y = LAGE.y + 1"
  modi: "D"

ENGINE:
  function ULRM_D(LAGE){
      return {
          x: LAGE.x,
          y: LAGE.y + 1,
          z: LAGE.z,
          modi: "D",
          role: "right"
      };
  }

RESULT:
  LAGE bewegt sich nach rechts (y + 1).
